# План тестирования

## Локальная проверка
- [ ] `npm install` завершается без ошибок.
- [ ] `npm run build` создаёт production-сборку.
- [ ] Без `.env.local` показывается инструкция настройки, приложение не падает.
- [ ] На ширине 320–390 px элементы доступны и нет горизонтальной прокрутки всей страницы.

## Авторизация
- [ ] Регистрация с корректным email и паролем от 8 символов.
- [ ] Некорректный email отклоняется.
- [ ] Неверный пароль при входе отображает ошибку.
- [ ] Успешный вход открывает финансовую панель.
- [ ] Обновление страницы сохраняет сессию.
- [ ] Выход возвращает к экрану входа.
- [ ] Если подтверждение email включено, пользователь видит сообщение проверить почту.

## Операции
- [ ] Добавить расход 125.50 — строка появляется в истории.
- [ ] Добавить доход 50000 — сводка доходов увеличивается.
- [ ] Пустая, нулевая и отрицательная суммы не сохраняются.
- [ ] После перезагрузки страницы записи остаются.
- [ ] Запись другой даты появляется только в соответствующем месяце.
- [ ] Фильтр по типу работает.
- [ ] Удаление обновляет историю и сводку.
- [ ] CSV содержит дату, тип, категорию, описание и сумму.

## Лимиты
- [ ] Лимит 10000 и расходы 8000 показывают предупреждение 80%.
- [ ] Расходы 10001 показывают превышение.
- [ ] Лимит сохраняется после перезагрузки.
- [ ] Лимиты разных месяцев не перезаписывают друг друга.
- [ ] Удаление лимита убирает его только для выбранного месяца.

## Критические тесты безопасности
- [ ] Создать пользователя A и B.
- [ ] A создаёт операцию и лимит.
- [ ] B не видит данные A.
- [ ] B не может удалить/изменить строку A, даже зная UUID.
- [ ] Вставка строки с чужим `user_id` отклоняется.
- [ ] `service_role` key отсутствует в bundle `dist/` и Git.
- [ ] RLS включён и все policies проверены в Supabase.
- [ ] Вызов Data API без сессии не возвращает финансовые записи.

## Перед релизом
- [ ] Проверить URL подтверждения email и разрешённые redirect URLs.
- [ ] Проверить HTTPS.
- [ ] Проверить поведение на Chrome Android и desktop.
- [ ] Проверить резервное копирование и восстановление.
- [ ] Указать контакт поддержки и политику приватности перед открытой регистрацией.
