# Мой бюджет — облачный финансовый трекер

React + Vite + Supabase Auth + PostgreSQL/RLS.

## Быстрый старт
1. Создайте проект Supabase.
2. Выполните `supabase/migrations/001_initial_schema.sql`.
3. Скопируйте `.env.example` в `.env.local` и укажите URL проекта и publishable/anon key.
4. Выполните `npm install` и `npm run dev`.
5. Перед публикацией пройдите чек-лист в `docs/TEST_PLAN.md`.

## Возможности
- Публичная регистрация по email и паролю.
- Облачное сохранение и синхронизация данных аккаунта.
- Доходы, расходы, категории, месячные сводки.
- Лимиты расходов по категориям и месяцам.
- История операций, фильтр, удаление, CSV.
- RLS-политики для изоляции пользовательских данных.

## Статус
Это исходный код MVP, а не уже опубликованный сервис. Для запуска нужны собственный проект Supabase, настройки переменных окружения, SQL-миграция, тестирование и deployment. В архиве нет реальных ключей или пользовательских данных.
